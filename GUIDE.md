# DIGIBAF Affichage — Mode d'emploi

<a id="installer"></a>
## 1. Installer et démarrer

1. Sur la TV, installez **Downloader** depuis le Play Store.
2. Dans Downloader, tapez le code DIGIBAF fourni par votre installateur, puis **Go**.
3. Installez puis ouvrez **DIGIBAF Affichage TV**.
4. Lancez l'**assistant d'installation** (touche OK sur l'écran d'accueil). Il vérifie :
   - la connexion Wi-Fi ;
   - le démarrage automatique (autorisez DIGIBAF) ;
   - sur les TV TCL : **Safety Guard → Auto launch permission → autorisez DIGIBAF** ;
   - la mise en veille automatique de la TV (réglez sur **Jamais**).

> Après une coupure de courant, la TV relance DIGIBAF toute seule.

<a id="associer"></a>
## 2. Associer au téléphone

1. Le téléphone et la TV doivent être sur le **même Wi-Fi**.
2. Dans l'app téléphone : **Mes écrans → Ajouter une TV**.
3. Choisissez la TV trouvée, ou tapez l'adresse affichée sur la TV.
4. Tapez le **code à 4 chiffres** affiché sur la TV, puis donnez un nom à l'écran.

> Pendant la diffusion, la touche OK de la télécommande affiche le code et l'adresse de la TV.

<a id="mur"></a>
## 3. Mur d'images

1. App téléphone : **Mes écrans → Mur d'images → Nouveau mur**.
2. Choisissez la disposition et le sens des TV, puis placez chaque TV sur sa case.
3. **Identifier les TV** : chaque TV affiche son numéro pour vérifier sa place.
4. Activez la **mire d'alignement** et réglez les bords avec − / + jusqu'à ce que les lignes soient droites.
5. Ajoutez la vidéo, choisissez le cadrage, puis **Envoyer sur le mur**.

> Toutes les TV du mur doivent être sur le même Wi-Fi.

<a id="depannage"></a>
## 4. Dépannage

- **La TV n'apparaît pas sur le téléphone** : vérifiez le Wi-Fi et que l'app TV est ouverte, sinon tapez l'adresse affichée sur la TV.
- **La TV ne redémarre pas seule** : relancez l'assistant d'installation.
- **L'écran s'éteint tout seul** : désactivez la mise en veille automatique dans les réglages de la TV.
- **La vidéo saccade** : MP4 (H.264), 1080p ou 4K, 30 images par seconde maximum.
- **Mur décalé** : relancez la mire d'alignement et vérifiez l'écart affiché sous chaque case dans l'app.
